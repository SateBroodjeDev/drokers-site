# 👋 Persoonlijke GitHub-profiel-README

De persoonlijke profieltekst wordt afzonderlijk van deze website-repository bewaard en gecommit. Een eventuele lokale kopie onder `github-profile/` wordt door Git genegeerd. De profieltekst bevat een Nederlandse introductie, projecten, technieken, persoonlijke interesses en een uitklapbare Engelse versie.

## Plaatsen op je profiel

1. Maak op GitHub een **openbare repository met exact de naam `SateBroodjeDev`**, als die nog niet bestaat.
2. Plaats je afzonderlijk bewaarde profieltekst in **`README.md` in de hoofdmap van die repository**.
3. Commit die wijziging. GitHub toont deze README vervolgens bovenaan je persoonlijke profiel.

De project-README van deze website blijft apart. Deze map is alleen de bron voor de profieltekst; er wordt vanuit dit project niets automatisch naar je profiel gepusht. Als er al een profiel-README bestaat, vergelijk de teksten voordat je hem vervangt.

De voorwaarden staan in de [officiële GitHub-documentatie](https://docs.github.com/en/account-and-profile/how-tos/profile-customization/managing-your-profile-readme).

## Onderhouden

Werk functies, projecten en technieken bij wanneer ze veranderen. De tekst gebruikt alleen bevestigde gegevens en bevat geen privécontactgegevens, hostingaccountinformatie, verzonnen cijfers of externe statistiekafbeeldingen. De Engelse tekst staat in hetzelfde bestand en moet bij inhoudelijke wijzigingen mee worden bijgewerkt.
