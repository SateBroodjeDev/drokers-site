# Logo-startbestanden

Deze bestanden zijn voorbereide merkbeelden uit de officiële bronnen in [sources.json](sources.json). Varianten en importgedrag staan in [Bedrijfslogo’s](../../docs/bedrijfslogos.md).

`OrganizationLogoSeeder` neemt ze bij een expliciete portfolio-import over in de private mediabibliotheek. Plaats de bronnen niet onder `public/`. De applicatie levert uitsluitend de gecontroleerde mediaversies voor gepubliceerde inhoud. Alle logo’s blijven via het portaal vervangbaar; het sitethema verandert hun kleuren niet.
